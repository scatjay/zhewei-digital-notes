# 學者與專有名詞總檢查（0918 工作坊逐字稿）

## 用途與涵蓋範圍

本清單供楊老師（工作坊籌辦人）在活動隔日核對用。逐字通讀以下四份「最終校對版」逐字稿全文（目前網站上實際顯示內容的來源）：

1. 第一場（笛卡爾／維柯／康德等哲學史脈絡＋卡片盒筆記法源起，講者張哲瑋）
2. 第二場（Obsidian／AI工具操作，講者張哲瑋）
3. 第三場（林文源教授談「研究規範」／AI時代學術倫理）
4. 圓桌論壇一（引言人：林文源、李卓穎｜主持人：陳登武）

逐字稿是 faster-whisper 本機 ASR 轉錄後人工校對的版本，已知修正案例（陳登武、水經注、洛陽伽藍記、王道維、李卓穎、盧曼、吳密察等）皆已在原始校對紀錄中處理，**本清單重點是找出「校對時沒抓到、但仍殘留在目前最終文字裡」的疑似同音誤聽**，以及把校對者自己標記過「低信心 / 待查證」但沒有動筆的項目集中列出來，供楊老師快速複核。

判斷方式：逐字通讀四份全文（含分頁 page_transcript／full_text），並交叉比對各檔案內附的 `corrections_applied` / `proofread_corrections` / `corrections` / `low_confidence_notes` 欄位，找出「同一人事物在不同場次寫法不一致」「校對記錄本身標記不確定」「上下文語意不通」三類線索。

**本次最重要的兩個新發現**（既有校對流程沒抓到、但有高信心佐證）：
- 第二場 page 35/37 出現「**陳東老師**」——第一場已確認「陳登武老師」的正確寫法，本場同一情境（帶讀《洛陽伽藍記》）卻殘留舊誤聽版本。
